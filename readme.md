
# Тестовое задание: сбор и семантическое обогащение данных о местах (POI)

> Выполнение тестового задания не обязательно для участия в отборе на проект, но значительно повышает приоритет в рейтинге.

## Цель

Построить базовый пайплайн по сбору и структурированию информации о местах (Points of Interest, POI), которые могут использоваться в рекомендательных системах и разговорных гидах (conversational guides).

**Ожидаемый результат:** небольшой датасет мест (кафе, рестораны, достопримечательности, парки и т.д.), обогащённый семантическими признаками, полезными для поиска и рекомендаций на основе пользовательского намерения (intent).

---

## Условия участия

1. **Количество заданий:** всего доступно 6 заданий. Можно выполнить любое количество, начиная с одного. Чем больше заданий выполнено, тем выше шансы на успешное прохождение отбора.
2. **Формат сдачи:** каждое задание должно сопровождаться отчётом в Jupyter Notebook или ссылкой на Google Colab с подробными комментариями. Исходный код должен быть размещён на платформе [git.miem.hse.ru](https://git.miem.hse.ru).
3. **Критерии оценивания:** количество выполненных заданий, качество кода, полнота анализа и корректность предложенных решений.

## Задание 1. Сбор датасета мест

Собрать датасет из **50–100 мест**.

### Возможные источники данных

- Google Maps
- OpenStreetMap
- TripAdvisor
- 2GIS
- Wikipedia
- Туристические сайты
- Другие открытые источники

### Данные по каждому месту

Желательно собрать:

- Название
- Категорию (кафе, музей, парк и т.д.)
- Краткое описание
- Отзывы (при наличии)
- Город или регион

### Что необходимо описать

1. Принцип отбора мест.
2. Категории, включённые в датасет.
3. Использованные источники данных.
4. Ограничения на количество мест одной категории.

---

## Задание 2. Формирование семантических признаков

Определить набор признаков, полезных для рекомендательных систем и поиска мест.

### Примеры признаков

| Признак | Примеры значений |
|---|---|
| Тип опыта | Еда, культура, прогулка, развлечения |
| Атмосфера | Уютная, шумная, романтическая |
| Контекст посещения | Семья, друзья, свидание, работа |
| Бюджет | Низкий, средний, высокий |
| Время посещения | Утро, день, вечер |
| Популярность | Низкая, средняя, высокая |

### Возможные источники признаков

- Текстовые описания мест
- Отзывы посетителей
- LLM
- NLP-модели

### Что необходимо описать

1. Выбранный набор семантических признаков.
2. Обоснование полезности каждого признака для поиска и рекомендаций.

---

## Задание 3. Извлечение признаков

Реализовать пайплайн автоматического извлечения семантических признаков из текстовых описаний или отзывов.

### Возможные подходы

- Large Language Models (LLM)
- Text Embeddings
- Классификационные модели
- Rule-based методы

### Что необходимо описать

1. Использованные модели, библиотеки и инструменты.
2. Причины выбора конкретного подхода.
3. Рассмотренные альтернативы, их преимущества и ограничения.

---

## Задание 4. Разведочный анализ данных (EDA)

Провести анализ сформированного датасета.

### Основные направления анализа

1. **Распределение типов мест**
   - Количество мест каждого типа.
   - Соотношение разных типов опыта.

2. **Распределение атмосфер и контекстов**
   - Частотность различных атмосфер.
   - Популярные контексты посещения.

3. **Распределение категорий**
   - Количество объектов в каждой категории.
   - Сбалансированность датасета.

### Визуализации

Построить графики, иллюстрирующие распределения выбранных признаков и характеристики сформированного датасета.

---

## Задание 5. Эксперименты с поиском мест

На основе текстовых описаний, семантических признаков или эмбеддингов реализовать простой поиск мест по пользовательским запросам.

### Эксперименты

1. Реализовать базовую модель **семантического поиска мест**.
2. Подготовить несколько пользовательских запросов.
3. Продемонстрировать результаты поиска для каждого запроса.
4. Проанализировать качество найденных результатов.

### Примеры поисковых запросов

- "Уютное кафе для работы"
- "Романтическое место для свидания"
- "Недорогое место для ужина с друзьями"
- "Интересное место для прогулки с семьёй"
- "Тихое место для отдыха"
- "Музей для посещения в выходные"

### Что необходимо проанализировать

- Насколько найденные места соответствуют пользовательским запросам.
- Какие признаки оказались наиболее полезными.
- Какие дополнительные характеристики могли бы улучшить качество поиска.

### Формат ответа

Загрузить файл со сравнительной таблицей результатов поиска и итоговыми выводами.
